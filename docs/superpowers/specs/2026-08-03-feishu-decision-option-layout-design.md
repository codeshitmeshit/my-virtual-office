# 飞书人工决策选项分组设计

## 目标

让飞书人工决策卡片中的 A、B、C、D 选项具有清晰的视觉边界，避免四个选项及影响说明被压缩成一个连续段落。

## 设计

- 继续复用现有通用飞书通知卡片渲染器，不新增飞书卡片协议或专用发送器。
- 人工决策 intent 的 `details` 不再包含单一的“ABCD 选项”长文本。
- 每个选项独立成为一个有序详情字段，字段标题格式为 `A｜选项标题`；推荐项追加 `（VO 推荐）`。
- 字段内容只展示该选项的影响，格式为 `影响：具体影响`。
- 底部操作按钮继续保持 `A`、`B`、`C`、`D` 和“提交自定义”，避免长按钮在飞书中换行。
- 终态卡片格式、飞书回调值、通知机器人优先级、聊天机器人降级和本地 UI 均不改变。

## 验收

- 自动化测试直接构建真实飞书卡片，确认 A–D 分别位于四个独立 Markdown 元素中，而不是同一个元素。
- 推荐标识只出现在推荐选项标题中。
- 新发送一张不同幂等键的 Mock 卡片，在真实飞书中确认选项可辨识。
