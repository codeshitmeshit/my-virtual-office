## Why

当前 VO 缺少一份由用户维护、可持久化且可被 Agent 按需读取的个人背景资料，导致不同项目中的 Agent 无法稳定复用用户的职业、兴趣、聊天偏好、资金关注方向、VO 主攻方向和办公室目标等上下文。需要新增“个人资产”能力，同时把建档交互与敏感读取授权放回各自正确的产品边界。

## What Changes

- 新增个人资产的持久化资料能力，内置基本信息、当前关注/买入资金、职业、兴趣爱好、聊天偏好、VO 主攻方向和办公室目标，并允许追加可扩展内容。
- 新增与现有 VO 风格一致的个人资产总览、编辑和待确认建议页面；页面只负责展示、编辑与确认已经持久化或待确认的资料。
- 新增供 Agent 按需读取个人资产的受控上下文能力，使项目 Agent 可以在必要时获取与当前任务相关的信息，而不是无条件注入全部资料。
- 将敏感信息读取请求统一交给现有 HUMAN DECISIONS 能力处理；个人资产页面不保存授权 UI，也不新增独立的敏感授权页面。
- 新增一个可手动触发的个人资产建档 Skill，由 Skill 在对话中完成逐项询问、确认、跳过、追加和持久化；不提供页面内建档向导。
- 保留用户对资料新增、修改、删除和建议确认的最终控制权，并为后续新增资料类别保留扩展能力。
- 本期不提供资产行情、交易执行、收益分析、自动抓取外部账户、页面内建档流程或独立敏感授权中心。

## Capabilities

### New Capabilities

- `personal-asset-profile`: 定义个人资产的数据范围、可扩展字段、持久化、页面展示编辑和待确认建议行为。
- `personal-asset-agent-context`: 定义 Agent 按任务需要读取个人资产、敏感范围升级到 HUMAN DECISIONS、最小披露和使用记录的行为。
- `personal-asset-onboarding-skill`: 定义手动触发的 Skill 建档、逐项确认、跳过、追加和持久化行为，并明确不创建页面向导。

### Modified Capabilities

- 无。现有 HUMAN DECISIONS 作为复用边界，本 change 不新增第二套决策中心或授权状态权威。

## Impact

- 个人资产持久化模型与存储边界。
- 个人资产查询、编辑、建议确认及 Agent 受控读取接口。
- VO 控制面板的个人资产入口及已验收的三类页面。
- Skills Library 中的个人资产建档 Skill。
- HUMAN DECISIONS 的既有请求创建与审计入口，仅作为敏感读取的统一承接能力复用。
- Agent Prompt/上下文装配边界，确保只在任务需要时读取且不泄露敏感信息。
